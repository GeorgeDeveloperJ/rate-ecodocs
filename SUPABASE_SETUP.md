# Configuracion de base de datos online (Supabase)

1. Crea un proyecto en Supabase.
2. En el SQL Editor, ejecuta:

```sql
create table if not exists public.ratings (
  id bigint generated by default as identity primary key,
  department text not null,
  nombre text,
  email text,
  rating smallint not null check (rating between 1 and 5),
  comentarios text not null,
  page text,
  user_agent text,
  created_at timestamptz not null default now()
);

alter table public.ratings enable row level security;

create policy "insert anon ratings"
on public.ratings
for insert
to anon
with check (true);
```

3. Abre el archivo `supabase-config.js` y reemplaza:
   - `RATE_ECODOCS_SUPABASE_URL`
   - `RATE_ECODOCS_SUPABASE_ANON_KEY`

4. Publica/sube los archivos actualizados.

Con esto, cada formulario guardara la valoracion en la tabla `ratings`.
